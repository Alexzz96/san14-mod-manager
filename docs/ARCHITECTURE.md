# 模块与扩展

`manager_main.c` 提供独立管理器入口，复用 `manager_ui.c` 和 `features.c`。`package.c` 确认游戏文件存在并校验本项目已登记文件，把编译时嵌入的 DLL 安装到指定游戏目录。

`theme.h` 集中定义暖白、深色文字和陶土色强调色，游戏内与独立管理器、悬浮提示共用主题。界面仍由 Windows GDI 绘制，无网页运行时或联网依赖。

`package.c` 结合安装记录、当前包和已核对旧版哈希检测同名文件归属；`cleanup.c` 提供完整卸载。只枚举固定管理器路径及其 logs/backups 及 career/checkpoints 固定层级，不递归删除任意目录。删除前为全部文件持有读取和删除句柄、核对最终路径与硬链接数量；占用及只读文件在预检拒绝。删除标记失败时撤销已设置标记，再释放句柄；结果记录实际清理数及未知文件保留数。运行中的管理器拒绝删除自身，用户需从外部安装包卸载。游戏与存档路径不纳入清单。

游戏启动载入 `dinput8.dll` 后，`plugin.c` 转发系统 DirectInput 导出，不读取游戏版本或 EXE 指纹，在可读内存范围内核对实际待修改入口与调用位置，使用 MinHook 接入建造检查和交互阶段。地图适配层读取六邻格的墙体类型及当前领地势力，`rule.c` 执行连片计数；计到第六个立即停止，最多展开 5 个格、读取 30 个邻格。

`interaction.c` 区分预览与实际确认。超限格保留选择交互，实际确认拒绝并将提示请求发送给工作线程；`toast.c` 显示不抢焦点的 5 秒提示。工作线程读取配置、更新心跳并管理 F10 界面。热路径使用原子生效标志，不等待界面、文件或网络。

功能表字段包括 ID、配置键、名称、说明、分类、开关位、依赖和生效方式。总开关与功能依赖共同计算生效标志。关闭追加规则后入口快速返回原游戏结果，保留同次启动重新开启的能力；解码异常则保护性停用到下一次重启。

当前支持至多 31 个独立开关。近期适合维持单个 DLL；功能增多后可把游戏版本适配、业务规则、参数编辑及提示分别分文件。暂不提供任意第三方 DLL 动态加载。
