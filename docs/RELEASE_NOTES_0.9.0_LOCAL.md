# 0.9.0 单页回合总结（本地验证版）

已确认的 HTML 样式接入原生游戏弹窗，无需网页运行环境。

- 探索汇总固定置顶：获得金钱、发现武将、名品、战法书。点击数字查看对应执行武将、地点及结果，点击标题查看全部明细与失败。
- 自势力战斗使用本地游戏头像卡片，显示斩敌、折损、杀损比值及击破／单挑／擒获标记，所部覆灭使用灰红色和灰化头像。
- 点击武将查看本回合相关记录；重要战事显示已记录日期、城市／府；逐条明细可展开并完整滚动。
- 右上 ×、底部按钮或 Esc 手动关闭，F10 的上一回合报告入口可重新打开；读档清空上个世界的报告。
- 探索和战斗使用结构化快照，头像独立线程解码，只读取玩家自己的资源包，不附带游戏素材。不新增游戏补丁入口或函数调用。

已核实的事件按原有口径计数，未核实候选保留明细；斩敌包含伤兵，无法等同实际阵亡。此页是当前回合报告，F 清单仍显示随存档长期累计战绩。

独立测试覆盖真实资源、武将／头像编号区分、压缩纹理、数据深拷贝、回合配对、战斗归属及结果、点击明细、完整滚动、关闭重开和 96／192 DPI。新增单页弹窗仍需游戏内完成一回合验收。本轮仅本地打包安装，不上传 GitHub。
