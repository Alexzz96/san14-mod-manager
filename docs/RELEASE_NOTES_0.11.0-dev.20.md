# 0.11.0-dev.20 · 内政名单兼容及载入提示

- 内政全表读取兼容预留/自建武将未初始化空记录，避免候选人已显示但府规划因名单校验失败而为空。真实编号错位、类型错误和异常任职官员仍拒绝。
- 进入存档后后台解析完整内政快照，解析成功且没有有效保存设置时才自动打开快速设置。回合结束不再触发，旧的已显示标记不当作已设置。

- 日志增加城市、府、武将数量和快照失败原因，编号异常提示包含具体槽位。

独立测试和本地构建不等于实机验收；不同剧本及该存档的府列表、首次进入提示仍需在游戏中核对。本版本继承 dev.19 的管理器关闭按钮及科技测试开关修复。
