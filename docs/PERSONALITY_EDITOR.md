# 通用个性编辑（0.11.0-dev.1 开发快照）

这是基础框架的已接入部分，完整六页编辑器尚未完成，不是首版候选包。实机验收待执行，详见 [实施记录](FOUNDATION_IMPLEMENTATION.md)。

载入存档后按 F，选中武将，点击 **个性配置**，或使用右键同名入口。面板不因失去焦点消失。

- 搜索名称、编号（可带 #）或说明，选择本机个性目录项；目录定义只读。
- **暂存添加** 使用第一个空槽；满槽时禁用，不挤掉已有个性。
- **暂存替换选中槽** 只改明确选中的非空槽。
- **暂存删除** 清空明确选中的槽，保持其他槽和顺序。
- 点击 **应用** 才将全部暂存修改提交为一个请求。**撤销暂存** 不修改游戏；**刷新** 放弃暂存，读取当前状态。
- 不新增重复编号；未改动的原始重复项允许原样保留。隐藏、未命名项按编号识别。已排队时禁用编辑和刷新。

## 槽位及执行

本机人物有九个 uint16 个性槽 `+0x150..+0x160`。编号 0 为空，1..355 属于目录；原生页面最多显示五项，不等于剩余槽为空，也不保证所有隐藏项都在任意场景生效。

请求保存世界、人物指针、人物 ID、存档会话和完整 512 字节修改前快照。提交及执行前均核对，10 秒未被处理的请求过期；读档、会话变化、回合执行或关闭编辑功能取消未执行请求。结果按请求编号保留最近 64 条。

所有修改沿用既有原生规划回调，在游戏线程执行。先检查本次全部目录定义和部队对象，逐个变更槽在必要时调用旧效果清理 `0x2748b0`，再调用原生 setter `0x21d5f0`。setter 对变更槽清理激活位及计时。最后复读九槽，只有完全一致才报告成功；已调用但复读失败时明确提示部分处理，需要刷新检查。

## 保存和回退

成功后请正常保存游戏。没有新增人物覆盖配置，不在每次读档时自动覆写人物。关闭编辑不会撤销已经执行的修改；读回修改前存档用于回退。

独立测试已验证目录编号、暂存、批量增替删、重复/容量校验、旧效果清理顺序、快照/身份保护、请求编号、取消及失败报告。模拟原生函数的通过不代表真实游戏效果已验证。全目录效果、邻队清理、保存重启和旧档回退仍待实机验收。
