# 武将个性配置（0.10.9 本地测试版）

0.10.9 修复预留空武将记录导致 F 清单全空的问题。确认未初始化的记录才跳过，真实编号异常、非空效果及不稳定读取仍拒绝；本机读取已恢复 1400 位武将。

载入存档后按字母 **F**，选中武将，点击 **个性配置**；也可右键武将选择同名菜单。面板手动关闭，不因失去焦点消失。

当前预设为 **远矢（本机编号 6）**。本机定义的说明是：自部队为【弓弩】且位于自势力内时，射程加一格。使用游戏本身的效果逻辑，不修改所有武将共享的个性定义。

- **新增远矢**：按槽位顺序选择第一个空位，不挤掉已有个性。全部占用时禁用新增。
- **替换选中槽**：先选中已有个性所在行，只替换这一格。空位使用新增操作。
- 已有远矢时，禁止重复新增或替换为重复远矢。
- **刷新**：重新读取该武将的槽位。修改成功后，面板与 F 清单的个性及搜索数据同步更新。

## 槽位与隐藏个性

本机武将对象有 **9 个 uint16 个性槽位**，偏移 `+0x150..+0x160`。原生详情界面扫描槽位、按定义和页面过滤，最多展示 **5 项**。这不意味着后四格全部属于隐藏个性，也不意味着看不见的槽位为空。

面板完整列出 9 格。未命名的非零个性显示“隐藏／未命名 · #编号”；新增不会覆盖它们。替换隐藏项也只改明确选中的格，其他槽位与顺序保留。扩展槽中的个性是否实际参与某条效果，仍受游戏自身的槽位、激活及分类判断限制；不能将新增成功等同于全部场景生效。

## 修改与保存

UI 提交请求，既有原生规划更新回调在游戏线程执行。回合执行、读档、武将槽位或会话发生变化时拒绝修改。检查本机远矢的名称、效果分类及数值后，调用原生槽位设置函数 `0x21d5f0`。

已出征武将替换非空槽时，先调用原生旧效果清理 `0x2748b0`，再设置新编号；由原生函数清理对应激活位和计时，不修改其他个性槽位。修改后的部队条件效果由后续原生更新重算。

**修改后请保存游戏。** 原生序列化包含个性槽位，插件不另建个性覆盖文件。关闭插件不会撤销已写入武将的个性；读回修改前存档可回退。当前保存、重启、读档及远矢实际射程尚待实机验收。
