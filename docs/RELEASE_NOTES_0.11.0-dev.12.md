# 0.11.0-dev.12 · 手动原生任命

修复区域官员配置只能预览、无法实际任命的问题。用户要求实际任命后，本地候选开放“统一应用”，在已有战略更新回调中复核方案和实际余额，按城市构造原生列表，调用游戏结算扣费及清理旧任职，随后复读官员、方向和准确命令书扣费。界面线程不修改游戏，不直接写区域字段，不随回合自动执行。

手动执行开放与实机验收完成是两个状态，当前实机验收仍为 pending。入口签名、总开关、会话、候选资格、锁定、预算、过期预览、重复提交、关联取消和失败停止检查保留。应用结果显示在原窗口，完成后必须刷新才能再次提交。

转任后空缺的撤职行显示方向清空，与任命行整组选择并计费。增加逐请求/城市/区域日志，记录拟任和实读结果、原生返回及余额前后，便于实际任命与扣费验收。工作线程及时刷盘。

回归覆盖默认构建启用执行、足额方案的界面提交、防重复点击、执行关闭、过期、预算、读档、批次失败、原生清理旧任职的互换和隐含撤职，保留600组分配对照及三档DPI检查。仅本地候选，按用户指定通过MOD管理器安装到本体，不修改SAN14PK_SC.exe；游戏退出后才替换DLL。
