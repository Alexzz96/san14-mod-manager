# 0.11.0-dev.11 · 开发数值、个性与治安规划

Ctrl+G 打开人物规划，增加“综合最高开发数值／全部商业／全部农业”。默认重新优化、治安优先；治安未满100的区域先最大化每旬恢复，再最大化开发净增。关闭治安优先后，开发净增优先、同分优先治安。补齐空缺、锁定、保护职务与关联取消继续有效，开发模式只改变可调整区域。

从当前存档读取个性定义、九个个性槽、开发现值与治安；调用原生开发、治安和每旬开发金费用计算。商业、农业、兵营均按1000上限计算净增，治安按100上限计算。王佐／能臣和柱石先计算每人的原生效果，再在驻城人员之间取最高；保护职务仍可贡献驻城加成，英名等驻军效果只作说明。详情同时显示文化、征税、农政、教化、能吏、安抚、占卜等原生说明，不把开发值转换为收入。兑现增量需要足额开发金。

新增14列及可滚动详情，显示原／拟任方案每旬增量、拟任三项增量、当前开发值、治安预测、相关个性、每旬金费用与任命命令书。摘要随取消关联调整更新。预测固定当前相邻任命、驻留和政策；转任后的关系及下旬事件可能改变实际结果。

本地隔离测试覆盖600组穷举对照、三种模式、治安优先、保护职务、上限、原生数据适配和96/144/192 DPI。静态核对19个原生入口。真实新计算入口与任命、扣费、刷新、保存读档尚待手动实机验收，应用 gate 保持关闭。仅生成本地候选，不发布 GitHub，不修改游戏EXE，不替换运行中的DLL。
