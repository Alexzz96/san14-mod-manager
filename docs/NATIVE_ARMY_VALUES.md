# 曹仁部队数值解析（0.9.2 样本，0.9.3 增幅显示）

以曹仁（武将编号 518）验证数值来源。0.9.1 的解析条与明细窗口已由用户确认显示；0.9.2 已取得原生真实返回：曹仁当前样本的攻军、攻城、防御白字及实际值与公式一致，生效列表与五项汇总一致。详见 [当前数值核对](ARMY_RUNTIME_0.9.2.md)。机动追加政策与完整回合稳定性仍待验证。

F10 → Mod → 武将情报 → 曹仁部队详情·数值解析。打开原生曹仁队基本页，点击上方数值条查看明细。滚轮、滚动条、Page Up/Down 查看长内容；右上角或 Esc 关闭。

## 白字

- 与游戏同一次计算的白字整数，阵形系数及兵种政策返回倍率。
- 主将基础统率、原生计算使用的有效统率与两者差值。
- 统率和兵力的耦合项、统率线性项、常数项。后续士气、原生全局、地形处理后的公共计算值继续列出；没有将其全部误称为统率增幅。
- 政策名称、原生返回强度及倍率。强度不冒充政策面板中的等级。
- 攻军、攻城、防御的公式核对：阵形 × 政策倍率 × 公共值 × 全局系数 × 白字效果倍率，防御另加原生常数 1，再截断。核对不一致时显示未分解差额。
- 破城、机动使用各自公式，不套用攻军的公共倍率；目前展示阵形、政策、效果层和临时字段，完整独立公式继续保留未解析边界。

## 蓝字

蓝字是实际整数减白字整数，不是独立相加的所有百分比之和。

- 府/领地入口的实际返回倍率、累计单位、所在及相连同势力府的计算输入。该入口还存在难度修正，未把全部返回值都认定为纯府加成。府的两个数值字段尚未命名。
- 原生认定的连携部队数量、当前配置的每支百分比和对应倍率。
- 白字/实际公共值之比，扣除已解析府与连携后的其余公共状态倍率。未采到府或连携时，该余项仍含未采集来源。
- 白字与实际分支各自的个性/状态百分比，专项、全能力、附加和条件单位，原生夹限及步长。
- 生效个性/传播列表逐项合计只有与原生五项缓冲区一致才标为已核对；依赖资格重算的分支或不一致来源保留未解析。
- 各属性临时 buff 独立显示。战法施放者仍待对应；格挡、免疫、陷阱等效果不转换为攻防百分比。

持有个性说明另供核对。持有、激活、参与五项数值计算是不同状态。

## 接入

11 个独立观察入口只观察游戏自然更新原生基本页时的计算，每次原函数调用一次，保持参数、整数/浮点返回与 LastError。观察模块不主动调用原生函数、不增加攻防、不访问存档。原生线程只做有界读取、局部计算快照和不等待的发布；来源解释、绘制、日志在工作线程完成。

0.9.3 的独立 [曹仁攻防增幅 Mod](CAO_REN_BUFF.md) 使用另外两个属性入口，启用时会改变实际攻防。解析明细显示原生浮点、插件倍率和增幅浮点，白字仍采用原生基础分支；蓝字包含插件增幅。解析视图关闭不会关闭该 Mod。

只读活动 UI 注册表与规范部队池核对世界、页面、对象及预览模式；关闭、切换、读档或身份不一致拒绝旧记录。日志 `army_attribute_view` 的数组顺序为攻军、攻城、破城、机动、防御，额外包含观测标志、两分支汇总、政策、阵形、府、连携、生效列表及白字公式核对结果。只在数据或可见状态变化时写入。

## 验证

独立验证覆盖对象与切换竞争、未知保留、阵形保护字段解码、原生五项汇总闭合及拒绝不一致来源、白字公式、统率兵力项、全部原函数调用次数与返回、LastError、11 个真实入口私有副本的跳板、日志截断保护、滚动与手动关闭。

这些测试不执行真实游戏函数。新层的政策/府/连携语义、白字公式在当前场景中的闭合及回合稳定性仍需要安装后的游戏内验证。
