# 特殊词条：闪袭 / 位移背刺

更新：2026-10-10。状态：**通用设计草案；已接入黄忠专属测试实现，实机待验收**。当前可用范围与验证记录以 [黄忠测试说明](HUANG_ZHONG_BLINK_TEST.md) 为准：默认关闭，仅主将编号 271 且原始姓名唯一为黄忠，后方三格，一笔普通直击 +30%，冷却与机会有效期各 5 游戏日。通用兵种挂载、配置参数和多笔攻击事件聚合不在本测试版中。

用户已经明确：多格是指**沿敌军后方逐格搜索落点**。不扩大初始锁定距离；从正面相邻接敌开始，移动拥有词条的来源部队，敌军本身不被移动。

## 首版行为

暂名“闪袭”，独立插件能力 ID 建议 `san14.blink_backstab`；不新增原生兵种编号或占用隐藏个性编号。用户已指定本次仅黄忠部队测试，代码配置键为 `HuangZhongBlink`；不改变既有 AI 词条抽取和城市保底。下面保留通用设计的约束与后续扩展方向，草案中未核实事项不代表已验收。

| 项目 | 草案规则 |
| --- | --- |
| 初始目标 | 一个已确认敌对、仍存活的相邻陆上战斗部队；目标归属实际接敌事件，不临时遍历挑选其他敌军 |
| 正面 / 后方 | 首版按本次来源到目标的接敌轴定义；真实敌军朝向尚未核实，不宣称识别原生正面、侧面、背面判定 |
| 落点 | 沿接敌轴越过敌军，按背后第 1、2、3 格顺序，取最近的空闲、合法且可供来源部队落脚的棋格 |
| 多格限制 | 默认最多搜索背后 3 格，作为可配置参数预留；相邻正面对敌时，来源到这些落点分别移动 2、3、4 格 |
| 穿越 | 作为闪烁，不占据或挤动途经部队；中间占位、不可落脚格可继续向后搜索，只有最终落点参与落脚校验；到地图边界立即停止。是否额外限制跨山、墙或关隘作为后续规则，不以普通行军路线假装已经覆盖 |
| 执行时机 | 本次交战的已核实安全结算点；正在使用旧棋格的攻击调用栈内只记录意图，不直接位移。首个接入必须先证实这个节点 |
| 失败 | 三格均不合法则不闪烁，不交换位置、不把别人推开，也不套用长枪受阻补混乱 |
| 背刺收益 | 闪烁成功后获得一次仅针对原目标的背刺机会；建议该次合法普通攻击的已确认直击伤害 +30%，数值未定案 |
| 攻击距离 | 背后第 2、3 格不自动获得隔格近战。等待游戏本身允许的普通攻击；无需改 AI 命令。首版不另造远距离伤害或强制追加一次攻击 |
| 有效位置 | 背刺结算时仍位于原目标接敌轴的后方，且原目标尚在原格；目标移动、移除、身份变化或双方不再敌对时失效 |
| 冷却 / 有效期 | 建议闪烁成功后来源冷却 5 个游戏日、背刺机会最长保留 5 个游戏日；数值是讨论起点，游戏时钟和到期节点仍需验证 |
| 重复触发 | 同一次完整交战事件只处理一次；本词条导致的位移或背刺不会递归触发本词条。闪烁成功即消耗冷却，即使后续未成功背刺 |

示意沿同一个六角方向展开，并非实际方格坐标：

```text
闪烁前：己方 A → 敌军 T → B1 → B2 → B3
优先级：                   1     2     3

B1 合法：A 落在 B1，后续合法攻击可结算背刺。
B1 被占、B2 合法：A 落在 B2，保留背刺机会，等待进入合法攻击距离。
B1 / B2 / B3 都不合法：本次不位移。
```

本设计没有保证“一落地立即追加伤害”。若后续决定一定要立即背刺，需要再定位完整攻击发起接口，处理额外攻击、反击和战绩归属，不能用直接扣兵冒充原生攻击。

## 已发现接口能复用到哪一步

分析样本和证据等级沿用 [长枪击退研究](LONG_SPEAR_KNOCKBACK.md)：当前 EXE 的静态调用已核对，运行时未观察。

| 接口 / 证据 | 对闪袭的用途 | 限制 |
| --- | --- | --- |
| `0x280570(来源格,目标格)` | 得到相邻接敌方向 `1..6` | 不是任意远距离目标的方向函数；返回 0 时拒绝 |
| `0x279EB0(棋格,方向)` | 从目标格出发重复调用，枚举后方 B1、B2、B3 | 每步检查无格哨兵 `48400`，不能使用格号直接加减 |
| 世界棋格表、`+0x1A / +0x1C` | 判断落点两类占位及对象有效性 | 与规划时读取的一致性必须在执行前再次核对 |
| `0x296420(落点,1,部队,0)` | 研究落脚地形 / 通行是否合法 | 此处部队必须是**被闪烁的来源 A**；不能照搬长枪代码传敌军 T。是否适用于多格瞬移尚未证实 |
| `0x2BB4D0`、`0x25A3E0` | 研究临时目的字段和旧格占位处理 | 必须操作 A 的字段和旧格，不能清空 T 所在格 |
| `0x257B2E0` → `0x2A97A0` | 研究当前修改版已有移动包装及位置同步 | 现有击退只证明相邻一步调用；多格位移、朝向、动画和其他副作用需单独验证，不能直接宣称可用 |
| `0x2CCD50` | 研究落地后路径处理 | 参数业务含义未完整解析；不能默认清除既定目标或自动追击 |
| 原有移动函数写部队 `+0x36` | 已见由旧格到新格的相邻方向计算结果写入 | 不能据此认定是战斗朝向。跨多格时相邻方向函数可能返回 0，必须追踪其消费者，确认多格会否产生异常方向或显示 |
| `battle_probe.c` 的动作、子效果和扣兵关联 | 研究背刺伤害的来源、目标和完整事件边界 | 当前没有已核实的通用普通攻击背刺上下文；战法、火伤、反击及重复扣兵须区分 |

长枪 `0x2482960` 规划器计算的是“让敌方目标后退一格”，`0x248306B` 会重新调用这个规划器。二者不能直接接受自行修改的多格计划：新计划会校验不一致，且移动对象本来就是敌军。因此应提取共同的身份、棋格与移动保护，另写“移动来源”的规划与执行适配。

## 公共位移能力应如何组织

建议与击退共用一个位移组件，定义移动对象、落点策略、最大距离、阻挡策略和成功后的附带效果；具体词条只负责触发资格与规则。

- 击退：移动目标，沿接敌轴一格；当前 EXE 另有自己的受阻混乱规则。
- 闪袭：移动来源，越过目标，从后方近到远寻找落点；位移成功后登记一次指定目标的背刺机会。
- 拉近、换位：以后另设规划器；不能从本次静态证据推断它们已经可用。

规划结果至少记录会话、世界、双方规范部队身份与创建序号、主将、双方原格、接敌方向、候选和最终落点、落点占位快照、原路径相关字段、事件编号及能力绑定。执行前重新选点核对；原计划失效时取消本次意图，不随意换目标。

背刺机会绑定来源与原目标身份、目标原格、接敌轴、触发事件和到期时间。伤害加成仅应用于经核实的一次普通攻击的直击通道；该攻击的多笔直击子效果使用同一个上下文，不能每笔重新获得机会、叠乘加成或反复刷新冷却。完整攻击结算后统一消费机会；攻击尝试失败不当成命中。战法、火烧、无来源扣兵和其他目标不使用该加成。

落地成功后复读 A 的当前格、原格已空、新格占位及 T 仍在原格，再登记背刺机会与冷却。已发生部分位移的故障单独报告并停止继续执行，不能按“未触发”反复重试；原有长枪的条件补救不等于完整回滚。

新冷却和背刺机会随正常游戏保存保留，并在读档、旧档回退及部队编号复用时保持正确归属；关闭词条取消未执行意图和未消费的背刺机会，保留已消耗冷却，重开不凭空刷新次数。具体附属存档格式仍需实现时设计，不直接改当前文件版本。

## 接入顺序与验收门槛

1. 用静态及只读运行观察确认 `+0x36` 的消费者、多格移动包装、路径处理与安全结算点；关联影响未知时不开放多格执行。
2. 先用可控单目标验证“正面相邻 → 来源闪到 B1”的纯位移，验证占位、既定命令、方向、显示、路径及保存重启。
3. 再验证 B1 被占 → B2，以及 B1/B2 被占 → B3；覆盖六个方向、边界、不可落脚地形和途中部队，确认不会移动或清理敌军。
4. 接入一次背刺机会，核对合法攻击距离、原目标归属、多笔直击不重复消费、目标移走失效和非普通攻击排除，战绩保持同一口径。
5. 核对与 EXE 长枪击退的组合时序：目标先被击退使原格变化时，本次闪袭计划失效；不在旧格上强行执行。
6. 最后接入词条展示、配置、概率及游戏时间冷却，验收多人围攻、部队编号复用、关闭取消、读档和旧档回退。
