# 0.11.0-dev.16 · 内政快速设置与初始化

内政移入基础功能。基础以外 Mod 新安装/初始化时全部默认关闭，日常更新保留用户显式设置。

首次真实回合结束后快速设置仅自动弹出一次，F10 或 Ctrl+G 可重开。三个预设：最高预计收益、商业满级→农业→兵营、农业满级→商业→兵营。

黑名单必不参与；白名单豁免统率阈值与临时筛选并优先任命，可以替换可调整的普通现职。原生有效性、同城、锁定、任务状态及预算仍约束任命。统率达到阈值排除。

独立管理器→设置→备份并初始化：退出游戏后，将全部插件配置、累计战绩、词条/兵种附属文件及日志移至游戏目录下 SAN14ModManager-ResetBackups 的独立备份，然后恢复默认配置与首次提示。保留已安装 DLL/管理器、游戏 EXE 和原生存档。重置不会更改原生存档内已保存的游戏状态；旧战績无法从原生存档重新补算。

本地测试包，不上传 GitHub。独立测试不代替快速设置的实机验收。
