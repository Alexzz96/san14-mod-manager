# 武将内心字段与拼音搜索

0.5.2 的武将快照模式版本为 2，新增野心 `ambition`、情义 `bond`、忠诚 `loyalty`。战绩提供者仍使用独立的版本 1；旧接口不变。

当前测试构建中，`CPersonData` 的 512 字节记录包含：

| 字段 | 偏移 / 原生类型 | 显示方式 |
| --- | --- | --- |
| 野心 | `0x1a2` / 有符号 16 位 | 原生转换为 1～5 级 |
| 情义 | `0x1a4` / 有符号 16 位 | 原生转换为 1～5 级 |
| 忠诚 | `0x120` / 无符号 8 位 | 保留实际数值；无所属、君主及俘虏显示“—” |

原生人物列表的格式化入口 RVA `0x310ef0`、`0x312470` 分别读取两个有符号字段，将 `-20 / -10 / 0 / 10 / 20` 映射到 `1 / 2 / 3 / 4 / 5`。其他值保留为未知，不能按猜测截断。人物忠诚格式化入口 RVA `0x3177c0` 读取完整字节；本 MOD 的数值可能高于 100，所以不套用其他势力页面的 100 上限。

已保存的只读样本中，张嶷两个字段为 `0 / 10`，对应野心 3、情义 4；本次用户提供的原生界面数值为情义 4、野心 3，与该样本一致。整个新增功能尚需更新后游戏内验收。所有偏移仅描述本地已检查构建，未对其他构建作普遍兼容承诺。

这些字段来自同一行双读和快照校验，不另装游戏钩子、不调用游戏内部函数、不写游戏数据。无所属或尚不适用的忠诚显示未知；已采集的 0 与未知不同。三项支持升降序，未知在两个方向都排到末尾。开发探测 JSON 额外包含三个原始值，便于以后核查；玩家列表只显示转换后的等级。

拼音词表固定于 `native/vendor/pinyin/readings.h`，源自 pypinyin 0.55.0 的 MIT 字典，包含简繁字和多音字，许可证随包附带。无需运行 Python、联网或在回合线程做转换。姓名、字、个性沿用空格分隔的 AND 搜索，各条件可用中文、完整拼音或首字母；大小写不敏感，吕布可输入 `lvbu / lubu / lb`。

多音字采用有边界的动态匹配，不穷举姓名组合；`张嶷` 可用 `zhangni / zhangyi / zn / zy`。原本的中文搜索仍可使用，拼音条件不能越过不同个性之间的标点。常用输入为不带声调的拼音，可匹配词中的连续汉字或拼音前缀。

普通构建使用已签入词表。需要更新字典时，单独安装 `pypinyin==0.55.0` 并运行 `python native/generate_pinyin.py`；生成后重新构建、验证，不把该工具依赖交给玩家。
