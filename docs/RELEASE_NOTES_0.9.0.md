# 0.9.0 · 单页回合总结与战绩管理

回合结束后，探索收获与自势力战斗现在放在同一页，不再需要切换标签。

- 探索顶部显示获得金钱、发现武将、名品和战法书；点击数字查看谁在何处找到了什么，点击标题可查看全部结果及探索失败。
- 战斗以游戏头像卡片展示斩敌、折损和杀损比值，区分击破、擒获、所部覆灭及单挑胜负。点击武将查看本回合明细，重要事件显示已记录的日期与城市／府。
- 报告支持完整滚动、手动关闭和 F10 重开。头像从玩家本地资源包异步读取；安装包不附带游戏素材。
- 整合此前本地 0.8 系列：Mod／设置管理器、可展开的主项及子功能开关、F 清单的统计／原始数据子页与 Tab 切换、四字战绩列、杀损比值、事件时间线与存档检查点。
- 已核实的普通单挑胜负，以及原生报告与俘虏状态匹配的抓捕路径，会计入战绩；其他候选保留明细并不计数。

新安装默认开启自动探索（各官员以外）和全势力战斗记录，墙体 5 格限制默认关闭；更新保留已有选择。

下载 **SAN14ModManager-0.9.0-windows-x64.exe** 即可安装，ZIP 包含同一安装器、说明和许可证。保存存档并完全退出游戏及旧管理器，在新版“设置”页选择游戏目录并安装，重新启动后生效。F 打开武将清单，F10 打开管理器。

独立测试通过，已包含窗口交互、纹理解码、事件归属、旧版安装升级和检查点恢复。此版为预发布：新总结仍需游戏内完整回合验收，其他抓捕路径尚待核实。斩敌表示敌方兵力减少（含伤兵），不等同实际阵亡；旧存档无法补算采集前战绩。
