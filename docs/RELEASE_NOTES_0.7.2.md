0.7.2 整合此前已在本地验证的功能，并增加 GitHub 在线更新。

- 基建 5 格限制新安装默认关闭；F10 可开启，更新保留原有选择。
- 安装与状态页支持检查新版本、后台下载与 SHA-256 校验，随后启动新版安装器；游戏内检查入口打开独立管理器，安装需要退出游戏。
- 字母 F：城市、野外武将统一视图；中文、拼音、首字母及个性搜索，能力、野心、情义、忠诚和累计战绩排序。
- 原生武将详情上方叠加累计战绩，随武将切换，鼠标穿透，F10 可启停。
- 回合自动探索与完整探索成功／失败明细，回合报告按探索、战斗分标签；战斗报告显示自势力，已支持战斗事件在全势力采集。
- 随成功保存的游戏存档建立战绩检查点；杀敌数按敌方兵力减少统计，含伤兵，不等于确认阵亡。历史从接入后开始。

下载 **SAN14ModManager-0.7.2-windows-x64.zip**（完整说明与许可证）或同名 **.exe**（独立安装器）。源码压缩包不能用于安装。先保存并完全退出游戏，关闭旧管理器，从游戏目录外运行新版，选择游戏目录并点击“安装 / 更新”。旧版首次升级需手动下载，以后的版本可在线检查更新。

已通过完整独立测试、规则对照、安装保留与回退、已知旧版迁移及卸载检查。此前的探索弹窗、武将视图、战报与原生详情战绩条已由用户在对应本地版本确认有效。非零战绩的重启恢复、旧档回退，以及两个已发布版本间在线更新仍需完整实机验收，因此保持预发布。

项目源码和附件不包含游戏本体、私人存档、战绩检查点或采集日志。更新不检查游戏版本号或 EXE 指纹；运行接入仍需校验实际代码与内存位置。未承诺兼容全部游戏构建。
