## 使用与构建

新个性界面：载入游戏，F 选中武将 → 个性配置 → 搜索并选择目录项 → 暂存添加/替换/删除 → 应用。详情见 [个性编辑](PERSONALITY_EDITOR.md)。本轮没有向游戏目录安装插件；需要明确选择后再安装开发包。游戏 EXE 保留。

构建固定使用 Zig 0.15.2 和 Python 3.12+。请指定本机可用的 Python 解释器；Zig 位于 `.tools/zig/zig.exe`，无需修改系统 PATH。

```powershell
python tools/get_zig.py
python native/build.py --zig .tools/zig/zig.exe
python -m unittest discover -s tests -v
python native/verify_native.py
python native/package_release.py --local --development
```

`--development` 必须与 `--local` 一起使用。普通本地候选和公开预发布路径都会因计划未完成而拒绝打包。开发包清单包含 `release_status=development_incomplete`、`first_version_candidate=false`、缺失操作列表及待验收标记。

- 35 项 Python 测试；包括相邻回调不误认虚函数、非代码指针和损坏 PE 的只读清单测试；固定编译器完整构建。
