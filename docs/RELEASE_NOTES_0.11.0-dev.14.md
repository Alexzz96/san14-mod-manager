# 0.11.0-dev.14 · 手动结果与自动刷新修复

复查 dev.13 的自动内政衔接时，隔离测试复现：手动预览或应用已经完成，但窗口尚未读取结果，自动补齐覆盖共用结果槽，窗口可能一直等待。修复为单独保留最近手动结果；成功和失败结果不丢失，被后台替代的预览明确失效并重新读取，旧预览不能提交。

自动任命变更标记改为与结果一起在锁内发布。窗口刷新遇到忙碌时保留待刷新状态并在后续回调重试读取，避免消耗变更标记后永久漏刷新；重试仅获取快照，不重复任命或扣费。读档和窗口关闭取消待刷新状态。

新增回归覆盖自动请求覆盖手动预览/应用、旧预览拒绝、完成结果及余额保留、忙碌后恢复刷新、失效预览自动重读，保留原有预算、去重、失败停止及原生入口检查。沿用 dev.13 的直辖过滤、确认进行后先内政再探索、锁定排除与部分预算补齐。真实自动任命、保存读档及复杂场景仍待用户实机核对。

仅本地候选，通过管理器更新本体；不改游戏EXE，不发布GitHub，不覆盖运行中DLL。
