新安装默认开启自动探索和战斗数据记录，让探索与武将战绩统计开箱即可使用。

- 自动探索默认开启，执行武将默认选择“各官员以外”；返回天数仍为“10 天以内”，优先级仍为“优先军师推荐”。原生游戏继续筛选任务资格并计算政令费用。
- 战斗数据记录默认开启。它是 F 武将清单和原生详情战绩条的新战绩来源；关闭时已有战绩仍可显示，但不会新增杀敌、击溃等计数，无法补算关闭期间的历史。
- 游戏内与独立管理器使用同一默认值，独立管理器刷新会同步战斗开关状态。
- 基建 5 格限制继续默认关闭。更新保留用户已有的配置；若旧配置曾关闭探索或战斗采集，需要在 F10 中手动开启。
- 保留 0.7.2 的 GitHub 在线更新。运行中的游戏需要保存退出后才能更新 DLL。

下载 ZIP（安装器、说明与许可证）或 EXE（独立安装器），任选一种。0.7.2 用户可直接使用“安装与状态 → 检查 GitHub 更新 → 下载并更新”。

发布前执行独立规则、原生代码、默认配置、显式关闭保留、旧版升级与卸载测试。维持预发布：非零战绩的跨进程重启与旧档回退仍待完整实机验收。杀敌数表示敌方兵力减少（含伤兵），不等于确认阵亡。
