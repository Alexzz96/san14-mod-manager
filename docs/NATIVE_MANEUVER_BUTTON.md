# 主菜单“武将”原生入口

主菜单“裁决”下方的 MOD 扩展行为“武将”，不额外创建第二个操演按钮。主项使用游戏原生 `CCmnSwitchButton`、状态回调和命中检测。右侧内容复用游戏已有的 `CMainCmdLinkLayout` 和其中第 10 个 `CCmnButton`（从零计数），遮罩使用 `CSubCmdLayoutBase`。子项沿用原按钮的字体、行为、输入登记和绘制顺序，不再创建独立子菜单控件。

游戏的主命令数组固定为六项，新增主行仍使用 sidecar 控件。扩展适配调用原生类别入口 `0x79f950` 的类别 5 流程，限定范围内接管 `0x7a5a10` 内容填充，随后设置扩展类别 6，并调用 `0x7a2e00` 原生遮罩定位。展开动画、侧栏压缩和收起恢复由原函数执行。`0x794700` 原生复位明确跳过大于 5 的数组索引；切换原类别前恢复借用按钮坐标，再由原生内容填充恢复名称与命令。原六项数组与十四个子按钮指针均不修改。

此前误把 base 的 `+0x200` 提示框与 `+0x208` 提示控制器当作子菜单，且绑定了 `0x1359170` 的整栏箭头回调，导致点击后直接收起。该登记已移除。真正的容器位于外层 `CMainCmdLayout+0x168`，子遮罩位于 `+0x170`；检查外层、容器、遮罩、按钮的实际 vtable 后才调用。借用子项的点击在原命令派发前被接管，防止执行原“提案”命令；原生关闭或切换类别时同步取消扩展主项选中。

扩展内容填充直接调用原生清空和背景布局函数 `0x7944b0`、`0x7a8400`，不再执行原“提案”填充或可用性检查。原按钮的提示回调 `0x7940a0` 在扩展打开期间输出“查看自势力武将清单及武将详情”，普通分类仍走原提示逻辑。

主项悬停新增独立的 `CMainCmdBtnCursorLayout`（RTTI 已核对），使用其原资源初始化 `0x797890`、原更新与绘制，以及 `0x7a4e10` 使用的同一动画 `0x787a70`、名称指针和速度 1.0。它在原菜单遮罩内绘制，离开、隐藏及销毁时通过原生方法隐藏、注销和清理，没有自定义颜色闪烁或呼吸插值。

点击“武将详情”后，先由原生复位收起子菜单；通过原生动画查询等待子菜单收起和主栏恢复完成，然后在同一 UI 线程读取当前自势力在职武将（按所属军团映射势力），默认选中君主，并调用原武将清单点击使用的 `CInformation` 入口 `0x3c5980(manager,list,selected)`。该入口复制名单到详情控件并消费临时原生名单。此前 `0x3c57f0` 是脚本等待包装入口，现已移除相应工作线程及暂停/等待处理。页面关闭仍交由原信息 UI 栈处理。打开前记录原地图状态、世界和菜单显示/登记状态；只在本次信息栈清空、原地图状态重新成为当前场景且生命周期稳定后，用原生 `0x789820`、`0x77c0e0`、`0x793c90` 恢复主命令容器与原控件登记，再调用 `0x7a3fc0` 恢复该菜单收起后的地图控件。恢复只执行一次；嵌套详情仍打开、状态切换尚未完成时不恢复。菜单销毁或世界/设置对象替换时取消恢复，已有其他信息页面时不接管。

`native_officer_entry.own_force_ui_submitted` 记录交给原 UI 的人数、势力、默认武将和请求累计次数，不表示页面已完成游戏内验收。离线测试检查同线程三参数 ABI、原生名单消费、自势力多军团过滤、默认君主、名单数量、场景变化、重入及页面源数据寿命。返回测试另覆盖信息页嵌套、原生场景切换等待、原菜单资源重新登记、重复帧不重复恢复和销毁取消。`native_officer_entry.map_return_ready` 记录返回条件已满足，`native_maneuver_button_state.map_returns` 记录原生恢复调用次数；实际按钮可见与可点击仍需游戏内确认。

插件日志中的 `native_maneuver_button_ready.ready=1` 表示钩子已安装。`native_maneuver_button_state.native_panel_links=1` 表示已找到实际原生子菜单与遮罩，记录其实际 vtable、失败阶段、主项/子项点击、展开次数和详情请求。该记录不代表画面验收通过。`native_officer_entry` 记录详情流程阶段。

F10 管理器与 F 武将一览仍由原生产插件注册。`hotkey_received` 能区分系统是否把按键事件投递给插件；之后的 `manager_toggle` 或 `officer_toggle` 表示对应界面已执行切换。焦点判断支持游戏拥有的前台窗口。

本次改动替换原“操演”占位行，并入生产 `dinput8.dll`。游戏手动验收需检查：F10 与 F 快捷键、主项悬停和按下反馈、子菜单展开/收起、详情页是否真实出现、关闭后原地图命令按钮是否恢复，以及反复打开和返回是否稳定。
