# 0.7.1 原生武将详情战绩条

打开游戏原生“武将详情”后，在右侧详情区域上方显示当前武将的杀敌数（含伤兵）、击溃部队、自身部队覆灭、自身兵力损失和击伤次数。数据与 F 武将一览共用，不另建统计口径或存档格式。此版不改变原生界面的按钮、姓名和人物资料。

战绩条采用管理器相同的暖白和陶土色，鼠标可穿透、不抢焦点。关闭原生详情、返回地图、切换应用或最小化游戏时隐藏；切换武将时根据当前页面编号切换数据。F10 → 更多拓展 → 原生武将详情 · 战绩条提供独立开关，外部管理器也可修改。对应配置是 `[Views] NativeOfficerStats=1`，设为 0 关闭，默认开启；更新保留已有选择。

F 武将一览仍只在打开时刷新。详情条每 250 毫秒只读检查原生 UI 注册表和当前人的数据，最多访问 2,048 个注册对象 / 256 KiB，不扫描整个进程或重读全部武将；取单行累计数据时仅访问插件工作线程内存。战斗采集关闭时仍可查看已有数字，采集缺口按统计后端的标记显示。

`detail_model.c` 静态校验原生选中数据赋值、基本页武将赋值及 UI 控制器入口，核对详情／标签页／基本页／武将的类型、两处选中指针、世界武将表和二次读取。页面未找到、已关闭、读档切换、身份不一致、多个匹配窗口或超出预算时隐藏；未知统计显示“未采集”，不伪装为 0。新增模块不调用游戏内部函数、不写入游戏数据、不增加游戏代码钩子。

布局采用原生 1920×1080 UI 坐标，根据游戏客户端大小缩放并处理宽屏留边；战绩条位于详情右侧上方，避免左侧“基本／能力／列传”按钮。已测试 1280×720、1920×1080、3840×2160 和 2560×1080 的坐标，真实显示位置和独占全屏可见性仍需实机验收。

## 验证

独立测试覆盖关闭、切换武将、身份冲突、切换期间指针变化、循环及预算限制、4K／宽屏布局、鼠标穿透、焦点和开关隐藏。生产读取器已通过只读进程权限定位本测试安装中的详情窗口，并读到曹洪（编号 511），用户确认当前页面确为曹洪；实际叠加位置、切换和关闭效果仍待安装后验收，不把静态和独立测试标为实机通过。

安装后先查看曹仁，确认战绩条姓名与原生姓名一致、数字与重新打开的 F 一览一致；再切换到其他武将、城市武将和野外部队主将，核对跟随。切换基本／能力／列传页、返回地图、切换应用、调整分辨率并关闭开关，检查隐藏与位置。`plugin-*.jsonl` 的 `native_detail_view` 记录显示状态、编号和计数，故障时用于核对。

诊断工具 `native/build/detail_probe.exe PID output.json` 复用生产读取器，只取得查询／读取权限，不注入 DLL，不显示叠加条或操纵界面。测试预览图使用模拟数据，不是玩家实际战绩。
