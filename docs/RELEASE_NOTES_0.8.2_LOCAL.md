# 0.8.2 本地武将清单双标签版

F 武将一览分为“战斗统计”和“原始数据”两个子标签，默认显示战斗统计。点击标签或按 Tab 切换；搜索输入框、下拉框和列表聚焦时也可使用 Tab，长按不会连续反复切换。

姓名、势力、所在位置固定在左侧。右侧随标签显示战斗累计或基础信息，横向滚动只移动右侧，两侧的纵向滚动及选中行同步。两页分别记住排序项目与方向，切换保留搜索、筛选和选中武将。移除底部武将档案，列表使用余下的窗口空间。

所有战斗计数以数字显示；原来“待核实”或未记录的项显示 0，按显示的数值排序。已有有效累计照常显示。0 表示当前可显示的累计记录，不代表已确认所有事件都未发生；后台仍保留有效位和原始候选，不把未经确认的抓捕等事件计入战绩。野心、情义、忠诚和兵力的不适用项仍显示“—”。

仍仅在按 F 打开时采集一次；切换标签、搜索和排序不重新读取游戏。手动关闭、Esc、原生武将详情战绩条、普通单挑累计及存档检查点保持原有行为。

独立原生窗口测试覆盖两页字段、Tab 的实际消息循环、固定列、滚动与选中同步、缩小窗口及滚动至末尾、零值显示和有效累计保留。安装后需实机检查 F 与 Tab；本轮仅制作本地安装包，不上传 GitHub。
