# 0.11.0-dev.13 · 直辖内政自动补齐

玩家确认“进行”后，独立开关 AutoDomesticFill 先补齐自势力直辖区域的空缺，再调用自动探索。关闭探索仍可自动补齐。自动补齐保留现职、不跨城调动，使用当前存档会话的开发模式、治安优先、锁定与排除；未打开规划窗口时使用综合最高开发、治安优先。开关持久化，规划选项仍只保留当前存档会话。

命令书不足时按治安/开发优先级选择可负担的整组调整，预算按账户合并；同一天/会话只执行一次。原生结算后准确复读任命和扣费，失败即暂停自动补齐及本次自动探索，不自动重试已扣费批次。读档和切换玩家重新校验会话，窗口关闭不取消正在游戏线程执行的自动请求。

探索候选及目标城市只允许玩家直辖军团，委任军团不参与派遣或结果统计。原生路线数组保持势力城市迭代顺序，委任城市对应空表，不压缩索引。本轮内政官员受保护，即使探索选择全武将，也不会再将其派遣。

手动应用完成后自动刷新原生快照、重新计算规划，并在原窗口保留执行结果。F10 测试功能和 Ctrl+G 规划窗口都提供自动补齐开关及状态。按旬实际开发金和当前关系计算的开发/治安预测沿用原生接口；不推断收入增幅。

dev.12 四个区域的实际任命、准确扣费与原生界面显示已由用户及独立只读快照核对。本版新增自动路径仍需用户实际点击“进行”验证顺序、刷新及保存读档；隔离测试和静态入口检查不能代替实机验收。仅本地候选，通过 Mod 管理器安装本体；不修改游戏 EXE，不发布 GitHub，不覆盖运行中 DLL。
