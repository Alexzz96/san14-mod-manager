# 验证状态

## 0.2.1 独立与静态校验

安装器和游戏内插件均已移除游戏版本、文件大小和 EXE SHA-256 白名单。独立启动检查接受不同指纹的同布局映像，8 种入口、调用点、架构、内存越界或不可读情况均安全拒绝，不写入错误位置。

已通过 2,000 组随机规则对照、512 种领地映射、线程隔离、DirectInput 转发、功能热切换的私有地图检查、提示时长和焦点，以及完整安装更新移除、未知代理保护、缺失游戏文件、未列入白名单的 EXE、文件占用回退和设置保留测试。安装器测试可在 CI 独立运行，无需游戏文件。

另对测试者选择的另一份 1.0.10.0 EXE 完成只读静态入口、虚表和 13 个调用位置核对，并在临时目录完成安装与回退测试。该 EXE 的指纹与旧白名单不同；无游戏进程内存写入，原 EXE 未更改。此结果不能代替游戏内验收。
