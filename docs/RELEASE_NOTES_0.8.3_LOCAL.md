# 0.8.3 本地战绩与时间线版

F 武将一览使用四字列名，按以下顺序显示：武将姓名、效命势力、驻军所在、斩敌总数、士卒折损、杀损比值、破敌次数、所部覆灭、斩杀敌将、击伤敌将、单挑制胜、单挑败北、擒获次数、被俘次数。姓名、势力、位置仍固定在左侧；两页按窗口宽度分配列宽，无需左右横移。单挑总次数和抓捕不同武将数不再显示，底部档案保持移除。Tab 切换战斗统计与原始数据。

杀损比值（本次 KDA）= 斩敌总数 ÷ 士卒折损，保留两位小数；斩敌为正而折损为 0 时显示 ∞，两者为 0 时显示 0.00。斩敌总数包含转为伤兵的人数，不能当作实际阵亡。排序按原始整数比值比较，避免显示四舍五入导致错误排序。斩杀敌将接口尚未核实，未记录时显示 0；不会从部队覆灭推算武将死亡。

点击姓名或右键武将行，在“战斗详情 → 查看时间线”打开详情；也可选中后使用“查看时间线”按钮或双击。记录包含发生日期、事件当时的城市与县府、交战对象、击溃／负伤／单挑／被俘结果。无法读取地区时保留棋格位置，未识别的城市和旧记录地点不猜测补填。双方武将均可查看相关事件。

普通单挑沿用已核实的胜负口径。新增抓捕归属校验：只有已匹配的原生战斗抓捕调用路径、有效敌对武将、成功返回值、同一父事件的抓捕文字报告和转为俘虏状态同时吻合，才累计个人擒获与被俘次数。其余抓捕仍显示候选明细，明确标注个人抓捕者待核实，不计入累计；这不是对所有抓捕路径的完整适配。既有候选不自动追溯改为已核实。

时间线新增独立 `.s14timeline` 检查点，与实际游戏存档内容摘要绑定，不改写原生存档或既有 `.s14career` / `.s14special` 格式。保存成功时写入，成功读档恢复对应时间线；失败读档保留当前记录，新剧本隔离，读旧档回退。只保存已有事件，空检查点小于 1 KiB。时间线保留最近 16,384 条全地图事件，超出后提示较早明细已截断；累计战绩继续由独立计数器保存。既有特殊事件可导入明细并标注旧记录，地点不补填；旧击溃累计无法还原历史明细。

每次按 F 打开时采集一次。搜索、排序、Tab 和时间线详情使用这次快照，不每秒刷新。二级菜单打开期间后台继续处理战斗事件，但不会刷新当前清单。备份或迁移时须一起复制游戏存档和 `SAN14ModManager/career` 目录。移除插件保留记录；彻底卸载会清理通过校验的时间线，未知或损坏文件仍保留。

独立验证包含比例与边界排序、四字表头、最小窗口宽度、双方时间线、原生抓捕关联校验、事件去重、跨进程恢复、旧档回退、容量截断及安全卸载。独立测试与静态接入点核对不替代新版本游戏内验收。安装后请核对一次新单挑或抓捕的姓名、日期、城市与县府，并保存重启确认恢复。本轮仅制作本地包，不上传 GitHub。
