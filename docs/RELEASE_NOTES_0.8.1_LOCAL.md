# 0.8.1 本地单挑累计验证版

普通单挑的胜负方向已由曹仁战胜张嶷的实机样本与原生结算分支核对。新增已核实普通单挑次数、胜场、败场累计，双方对手明细及回合报告显示胜者与败者。

原生调用链先依据胜负排列参与者，结算函数的第一武将是胜者、第二武将是败者，不能把附带整数参数作为胜负标记。双方原始站位不同的两条调用分支均已覆盖。只累计已匹配的普通单挑后果类别与有效敌对武将；未知上下文、其他后果或代码不匹配继续观察。

0.8.0 候选保持待核对，不自动补算。从新版本接入后新增的已核实普通单挑计数，随成功保存建立检查点，并在读档时恢复。

抓捕、被俘明细保留；实际个人抓捕者累计尚待接入报告归属校验。现有探索、杀敌、击溃及旧战绩格式保留。本轮仅构建本地包，不上传 GitHub。

更新后需通过新发生的普通单挑核对 F 计数与报告，再保存、重启和回退旧档验证非零计数。
