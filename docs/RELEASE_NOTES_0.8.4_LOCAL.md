# 0.8.4 本地 Mod 管理列表版

管理器整合为两个标签：**Mod** 和 **设置**。游戏内 F10 与外部安装器共用相同界面，沿用暖白、深色文字和陶土色强调色。

Mod 页用列表集中显示墙体连片上限、回合自动搜索、战斗数据记录与战绩、武将情报、诊断日志。右侧开关直接启停；左侧箭头或名称区域展开有子项的 Mod。支持默认排序、名称排序、已开启优先；排序和展开不改变任何功能设置。展开后内容超出页面可用滚轮或滚动条查看，Tab / Shift+Tab 导航，空格或 Enter 激活，焦点自动滚动到可见区域。

| Mod | 展开内容 |
| --- | --- |
| 墙体连片上限 | 超限悬浮提示的独立开关；仅在墙体规则开启时生效 |
| 回合自动搜索 | 执行武将、返回天数、重视项目；游戏内查看上一回合探索／战斗报告 |
| 武将情报 | F 武将清单与原生详情战绩条的独立开关 |

武将情报新增父开关 `[Views] Enabled`，缺省为开启。关闭父项暂停两个视图，同时保留各子项的选择；重新开启后按原来的子项设置恢复。旧版配置缺少这个键时行为保持原样，安装更新不重写已有配置。

设置页集中提供游戏目录、安装状态、安装／更新、移除插件、彻底卸载、日志、GitHub 更新，以及原有的规则与采集总开关。该总开关控制墙体、探索、战斗与诊断，武将情报保持独立启停。新装默认墙体限制关闭、自动探索开启且选择各官员以外、战斗记录开启；更新保留用户已有选择。

回合报告入口移到 **F10 → Mod → 展开回合自动搜索 → 查看上一回合报告**。报告的探索与战斗标签、F 武将统计／原始数据标签、时间线、存档战绩口径均沿用 0.8.3。

独立原生窗口测试覆盖两标签页、各 Mod 操作与配置读回、父项关闭后的子项保留和运行门控、排序后稳定归属、展开列表的滚动与裁剪、键盘自动滚动、安装及更新的运行中保护和两种 DPI。更新安装器登记 0.8.3 本地文件指纹，支持识别更新与完整卸载。本地版不上传 GitHub；安装后的 F10 操作仍需游戏内验收。
