# 0.8.0 本地观察版

本轮仅构建本地安装器，不上传 GitHub，不创建发布标签。

- 增加单挑结算与抓捕结算的观察入口，保留双方、日期、状态和原始结果，供真实游戏样本核对。
- F 武将一览增加六个特殊战绩列与排序接口，下方增加个人单挑、被俘变化明细。
- 未经验证的观察标记“待核对”，不会计入个人战绩；抓捕来源部队主将不自动算实际抓捕者。
- 新记录使用独立 `.s14special` 存档检查点，支持保存恢复与旧档回退，保留现有 `.s14career` 战绩。
- 两个新增入口可独立停用，不影响原有战斗采集；完整卸载识别经过校验的特殊检查点。
- 保留探索默认开启、各官员以外、战斗全局采集默认开启，以及基建五格限制默认关闭。已有明确配置保持不变。

真实游戏单挑与抓捕、非零新记录的重启及回退验证仍待完成。详细口径见 [特殊战斗事件](SPECIAL_BATTLE_EVENTS.md)。
