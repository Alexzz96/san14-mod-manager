# 0.11.0-dev.21 · 内政目录兼容审查

继承 dev.20 的未初始化武将空槽修复和进入存档后快速设置流程。

- 允许未使用的空城市、府及个性目录槽位；引用缺失城市、引用缺失个性、错误对象类型仍明确失败。
- 一次读取完整城市、府和武将指针表，区分空槽与读取失败；候选及驻留武将必须与武将表的对应对象一致。
- 读取失败的手动预览不再发布部分城市/人员，避免“部分武将显示、府列表为空”被误认为成功。失败的快速设置不反复自动提交，搜索也保留错误信息；载入后的后台读取仍按两秒间隔重试。
- 增加稀疏目录、引用缺失、错误类型、编号 6000、循环列表、缺失领地格及失败预览清空的回归测试。

本地游戏 EXE 的静态代码确认开发和治安函数最终至少返回 1，因此没有放宽该检查。不同游戏 EXE 的签名不匹配、128000 项预测容量、对象类型与数值边界保护继续保留。

独立验证通过不等于所有剧本都已经实机验证。
