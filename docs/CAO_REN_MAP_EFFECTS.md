# 曹仁地图特殊效果 · 0.9.6 本地版

F10 → Mod → 展开“曹仁攻防增幅”，可以分别开启“地图头像 · 紫色光圈”和“悬浮面板 · 特殊效果”。视觉子功能默认开启，但需要父 Mod 开启；通用安装包的攻防增幅仍默认关闭，更新保留已有开关。关闭一个视觉子功能不会改变真实攻军、防御倍率。

光圈在地图上标记曹仁担任主将的真实部队，读取原生头像裁剪圆与外框的位置，在势力色环外围绘制柔和紫色光圈。中央透明；光圈直接绘入游戏帧，没有额外光圈窗口，不参与鼠标命中。原生简略、编组或未核对的变换路径暂不显示光圈。

鼠标停在曹仁头像上、原生部队悬浮面板显示时，在个性列表下方显示“特殊效果 / 攻防强化 / 攻军 +10% / 防御 +10% / 当前生效 · 曹仁队 / 来源：Mod”。原生个性面板的背景高度是动态值，说明按这个实际高度放置。空间不足时尝试放到个性列表右侧；没有完整空间时隐藏，不覆盖原生面板。

退出悬浮、切换其他部队、部队覆灭、读档身份变化、打开详情或 Mod 窗口、切换到其他应用时，追加窗口隐藏。光圈在 D3D11 Present 提交前读取当前外框变换并直接绘制，使用浮点坐标与当前帧缩放，不依赖工作线程的 33 毫秒定位。说明卡片仍约 33 毫秒检查悬浮状态。两个开关可在游戏内改变，约 250 毫秒内读入。

## 接入与边界

- 视觉部分增加一个 DXGI Present 绘制入口，不增加游戏本体计算钩子，不调用游戏计算函数，不写部队、武将、地图或存档数据。真实 +10% 仍由已有攻防增幅模块处理。
- 只读取 UI 控制器当前地图、悬浮/详情两个容器。缓存发现结果，容器或游戏世界变化时重建，平时每五秒复核一次；所有读取有对象数、调用数与字节预算。
- 使用 CArmyInfoLayout 的规范部队指针和主将编号 518，校验世界部队表与活跃身份。悬浮基础面板和个性面板必须绑定同一规范部队，避免用全局“最后悬浮”的姓名推测对象。
- 光圈使用原生 CMapFaceLayout 的圆形裁剪及 64 格外框；在提交画面时从头像外框已更新的世界变换读取位置，仅使用这个坐标源，不交叉比较不同更新阶段的布局坐标。未更新或未核实的缩放/旋转不猜测位置。
- 日志 `cao_ren_map_effects` 记录接入与可见状态变化、绑定部队、位置与读取预算。仅显示状态变化时写入，不逐帧写坐标。

## 本地核对

2026-10-09 已通过生产读取器只读核对当前测试进程：94 个部队标记，曹仁部队 29；地图光圈矩形与原生头像外框匹配。用户悬浮曹仁后，基础面板与个性面板都绑定同一部队，说明区域为参考坐标 `[244, 500, 418, 674]`，在四项个性下方。缓存刷新读取 157 次、9468 字节，没有调用游戏函数。

独立测试覆盖规范身份、其他主将、死亡/隐藏、详情遮挡、世界切换竞争、坐标陈旧、动态个性高度、窗口缩放、空间不足、透明中心与预乘透明度。安装后仍需实际显示、鼠标穿透、地图拖动、切换武将及完整回合核对；只读成功不等于追加窗口已实机验收。本版本仅本地输出，尚未发布。


## 0.9.6 移动闪烁修复

0.9.5 的外部光圈窗口与游戏帧分别更新，多处坐标不一致时立即隐藏，整个采集失败还会等待 250 毫秒，形成闪烁。0.9.6 取消光圈的独立窗口；在 Present 前逐帧读取外框浮点坐标，只负责原生世界/规范部队/可见父级的身份校验。工作线程只提供对象绑定，坐标不从工作线程缓存继承。

使用独立 D3D11.1 上下文状态绘制，完成后恢复游戏的完整绘制状态。每帧释放渲染目标，并清空插件状态中的后台缓冲区引用，支持 ResizeBuffers。GPU 资源初始化失败后退避五秒，不每帧反复初始化。图形接入失败时停止光圈，保留悬浮说明和实际攻防功能，不回退到抖动的外部光圈窗口。

独立 WARP GPU 测试已核对光圈像素、透明中心、完整绘制状态恢复、缩放释放、真实 Present 入口和返回值透传；模型测试模拟 1024 个小数坐标移动帧及缩放。真正游戏的移动、缩放及跨回合稳定性仍需安装后核对。
