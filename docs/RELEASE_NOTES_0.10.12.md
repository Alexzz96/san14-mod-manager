# 0.10.12 · AI 出征词条与城市第九次保底（测试版）

AI 军队可以在出征时获得“禁军精锐”：攻军、防御 +10%，显示“禁 原名”、地图红圈和悬浮效果说明。

- 所有 AI 势力参与，包括盟友；玩家本势力不参与。每座城市第 9、18、27…次成功出征必出，其余仍按 10% 随机。提前随机命中不重置计数，长期平均命中率约 20%。
- 词条只绑定本次部队；回城、覆灭后结束，转入玩家势力停止效果。与曹仁同类攻防词条取最高，不叠加；特殊兵种倍率另行处理。
- 独立随机序列和城市计数随原生存档内容哈希保存，支持重启、读档及回退；不修改游戏 RNG、姓名、个性槽位或原生存档格式。
- 兼容旧版 V1 随机词条附属文件，保留词条及 RNG，新城市计数从零开始。编成、失败和重复创建不计数，存量部队及关闭期间出征不补抽。
- F10 → Mod 新增可展开“AI 随机词条”，新安装默认关闭，红圈和悬浮说明子开关默认开启。更新保留已有设置。

修复非中文 Windows 中探索连接状态的中文传输：使用独立 UTF-8 编码字段，兼容旧状态文件；保留严格测试，并输出云端失败断言便于诊断。

本版同时整合 0.9.0 后的本地功能：曹仁“百战精锐”及名称/地图效果、部队数值解析、高顺专属陷阵营的原生按钮和独立图标、1000 人上限、武将个性新增/替换面板（显示 9 个槽位和隐藏编号），以及探索归属、武将清单和地图遮挡修复。

## 下载与更新

下载 `SAN14ModManager-0.10.12-windows-x64.exe` 即可安装；ZIP 包含同一安装器、说明和许可证。保存游戏，完全退出游戏及旧管理器，再从游戏目录外运行安装器，选择游戏目录并安装。旧版本也可通过“设置 → 检查 GitHub 更新”下载本预发布版。F 打开武将一览，F10 打开管理器。

普通更新保留设置、存档、累计战绩及附属文件。安装包和源码不包含游戏本体、游戏头像素材、私人存档或运行日志。

## 验证状态

独立原生回归及 32 项 Python 测试通过。基础随机百万次命中 100208 次；城市保底 90000 次模拟中固定保底 10000 次，总命中 17977 次。失败/重复创建、城市独立计数、同类增幅去重、V1 迁移、独立进程恢复及旧档回退均有测试。

此前 0.10.10 的实机日志已记录 93 次 AI 成功出兵、7 次命中，并核对了 24 条非曹仁的 +10% 属性样本。这只验证已观察的创建与非战斗属性路径；**0.10.12 新城市保底、真实战斗数值、多部队视觉及完整回合仍待实机验收**。无法确认城市来源的出征保留 10% 随机抽取并记录 `city_id=-1`；关隘等来源的城市归并尚未扩展。

本版明确为测试预发布，不作为全构建兼容或强度验收完成的正式版。修改过的游戏 EXE 的兵种减伤适配仍未完成。运行时继续核对实际入口，不以游戏版本号或整份 EXE 指纹阻止安装。
