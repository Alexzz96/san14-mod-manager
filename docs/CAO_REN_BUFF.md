# 曹仁攻防增幅（0.9.4 本地测试）

F10 → Mod → **曹仁攻防增幅**，可独立开启或关闭。此功能增加实际战斗属性，和“武将情报”中的只读解析开关分开管理。管理器规则总开关关闭时也停止增幅。通用安装包默认关闭；本次玩家测试安装将开启该项。

## 作用范围与计算

- 只作用于曹仁（编号 518）担任主将的真实地图部队，任何势力均适用；其他主将、副将、出征预览或无效对象不适用。
- **原生实际攻军、防御浮点结果 × 1.10**，随后由游戏原生调用者取整。白字基础保持原生结果，蓝字差值包含插件增幅。
- 不修改统率、个性、阵形、政策、攻城、破城、机动或部队临时状态字段；没有接入斩敌门槛。
- 府、个性、战法等先按原生规则计算，再独立乘插件倍率。不写回属性缓存，不累乘，不依赖打开详情窗口。
- 关闭后从下一次原生属性计算起恢复原生结果。详情仍显示旧值时，关闭并重新打开原生曹仁队详情。

0.9.2 当前样本（5500 兵、士气 109）攻军浮点约 2696.43457、防御约 1285.01648；相同场景启用后预期整数 **2966 / 1413**。兵力、士气、位置和状态改变时数值随原生计算变化。

## 接入与边界

`native/army_buff.c` 在攻军 `0x283ad0`、防御 `0x27bd90` 入口截获游戏自然调用，ABI 为 `float(float, army*, target*, formation*, int actual, int mode)`；仅 `actual == 1` 的真实部队分支增加倍率。原函数各调用一次，参数、LastError 保持，有限非负结果才增幅。

部队需通过活动状态、主将编号、世界指针、512 字节规范部队池和索引表检查；原函数返回后再次核对身份。入口校验或创建失败时此 Mod 不启用。游戏 EXE 文件不修改。

静态调用链中，战斗攻军调用位于 `0x15ca40`，返回地址 `0x15cb70`；防御调用位于 `0x15c880`，返回地址 `0x15c99a`。它们与详情使用同一属性入口。真实交战时有界队列输出 `army_buff_applied`，包含原生/增幅浮点、部队编号及调用位置。原生线程不写日志、不等待队列；队列满时仅丢弃诊断样本。

解析日志 `army_attribute_view` 新增 `buff_seen`、`buff_percent`、原生/增幅浮点及 `plugin_buff_applied`。`snapshot_read_only` 表示采样只读；启用增幅的计算记录 `read_only: false`。明细显示原生值 × 倍率 → 增幅值。

## 验证状态

独立测试覆盖私有 MinHook 的 x64 浮点/栈参数 ABI、原函数调用次数、LastError、白字与其他主将不变、开关恢复、不累乘、身份竞争、非有限值、取整顺序、有界日志队列和增幅/解析快照集成。

测试不执行真实游戏函数。0.9.4 安装后用户已确认显示有效，日志取得部队 29 的三次攻军、三次防御真实交战调用；每次增幅浮点均对应该次原生结果 × 1.10。详情白字不变，攻军 2696→2966、防御 1285→1413。完整回合稳定性与关闭开关对照仍待单独核对。

0.9.3 实机曾因防御入口特征码漏掉开头的 `0x40`，显示“等待接入”而未增加属性。0.9.4 修正该字节，并在私有进程中用原 EXE 的真实入口字节执行生产安装函数，验证签名拒绝、失败回滚及成功安装。启动日志另记录 `install_code` 和 `failed_entry_rva`。仅本地输出，尚未上传 GitHub。
