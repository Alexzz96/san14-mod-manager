## 原生接入

- `native/tech_tree.c`：仅扩展武将详情 `CCmnTab`，私有列传页虚表继承原生资源与人物刷新 `0x80ba40`。资源 `0x950e4a5d` 的 0..18 为角色区，19..98 为右侧关系列传区，人物刷新后隐藏后者。角色图像由本体刷新。
- `native/tech_tree_ui.c`：在第四页下创建原生 `CCmnLayout` 容器，坐标 `(698,12)`、尺寸 `840×650`，跟随本体 1920×1080 逻辑坐标和父级缩放。所有图片、文字、按钮都为本体控件，没有额外 Win32/Web 窗口。
- 图标暂用本体兵种图：攻势“大戟”、守备“刀盾”、机动“重骑”。兵种栏的 MOD 兵种使用承载兵种图标配自身名称，未解析 SVG 图标。
- 按钮沿用原生 `CCmnSwitchButton` 的正常、悬停、按下、选中和禁用回调。私有行为只分流自己的点击和提供说明。锁定节点可以点选查看前置，显示原生禁用外观；升级按钮在条件不满足时真正禁用。
- 点击由已有 `0x77fd10` 事件钩子分流，在下一次原生页面更新中处理；不会进入裁决/提案的命令入口。
- 说明区在悬停时显示节点短说明；点选后展示名称、兵种、预览效果与前置条件。箭头按每页 5 个兵种切换。
- 连线由原生文本控件绘制，使用本体颜色表；解锁后点亮对应线段。图标和连线形状仍须手动检查游戏字体与纹理显示。

## 展示模型

`native/tech_tree_model.c/.h` 使用稳定武将 ID、原生 `native.N` 兵种 ID 与 MOD 注册 ID。原生兵种取人物 `+0x164` 权限位，位序就是兵种编号 1..20。MOD 条目同时要求注册表主将资格和承载兵种权限，不写任何原生兵种字段。

根节点“兵种整备”已解锁。三分支分别为“锋刃→精锐→破阵”“固甲→列阵→铁壁”“轻装→疾行→神速”。每个节点只接受一次演示升级，前置未解锁时不能升级。说明标为预览，没有正式加成数值。

每名武将分别记住兵种选择，每个兵种分别记住所选节点和解锁集合。切换其他武将或标签不清空进度；窗口释放时全部清空。控件分配失败时释放已建控件，原生详情窗口仍可返回。

## 生命周期和兼容

额外控件在页面显示时登记到原生输入/绘制表，隐藏时注销，关闭时先恢复按钮标题的弱引用，再注销并按逆序释放控件。私有虚表尾部有版本化身份标记，供只读战绩条识别新生命周期回调。保留新增地图入口默认第四页，以及原生地图菜单恢复流程。

## 手动验收

1. 从地图“武将→武将详情”打开：默认科技树，左侧完整角色信息，右侧没有关系列传残留。
2. 切换武将、兵种、四个标签：内容同步，进度按人物/兵种隔离，返回第四页仍保留。
3. 点选三个一级节点并演示升级：后续逐级开放；锁定节点可查看条件，重复升级不会发生。
4. 关闭后重开：进度重置；地图原有按钮正常。
5. 1080p、当前高分辨率、窗口模式：检查边界、图标、连线、文字、悬停及鼠标命中。
