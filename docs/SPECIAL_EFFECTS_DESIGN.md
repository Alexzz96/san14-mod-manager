# 武将部队特殊效果：扩展分析

日期：2026-10-09。仅分析及规划，没有启用新效果、修改数值或发布版本。用户确认 0.9.6 地图效果正常；运行日志确认 D3D11 Present 实际绘制已发生且错误码为零。此确认不扩大为所有跨回合、存读档及开关情形已经验收。

## 当前能力

已验证的数值改动是：曹仁担任主将的规范活动部队，原生实际攻军与防御结果乘以 1.10，白字不变，不反复累乘。身份、作用对象和绘制目前仍是曹仁单一样本，通用效果管理及多部队绘制尚未实现。

原生攻城、破城与机动 getter 已定位，但改动这些属性的真实战斗/移动路径尚需接入验证；机动在此整合包中另有追加计算分支。已观察兵力、士气、阵形、位置、府/城市归属、个性汇总、临时修正层、战法和状态施加事件，不等于这些内容都已经具备安全修改接口。

生涯战绩按存档检查点恢复，已记录斩敌量、损失、击溃、覆灭等可作为成长条件。“斩敌”口径为敌方兵力减少，包含伤兵，不是实际阵亡人数。采集之前、关闭或存在缺口期间不会补算；成长说明应使用“已记录斩敌量”。正常单挑胜负与已核实路径的抓捕不能推广为所有分支都已验证。

以下名字、数值均为讨论样例，并非新增原生个性或已实现功能。

这些能力可统一配置为词条，按战绩解锁并展示姓名前缀；具体“百战精锐 → 战-曹仁”方案与姓名代码入口见 [战绩词条与称号可行性](CAREER_AFFIXES.md)。

| 样例 | 激活条件 | 效果 | 接入评估 |
| --- | --- | --- | --- |
| 百战精锐 | 随存档累计已记录斩敌量达到 5000 | 攻军、防御 +10% | 复用攻防倍率入口；需通用对象和战绩缓存 |
| 坚守阵地 | 驻守当前所属势力的领地 | 防御 +15% | 阵营须由军团映射到势力，不能直接使用部队军团字节作为势力 |

| 高昂战意 | 当前士气达到设定值 | 攻军 +10% | 使用士气作为资格，不需要先实现士气写入 |
| 破城先锋 | 确认攻城或破城计算路径 | 攻城/破城 +20% | getter 已定位，修改真实城防伤害需验证，不只改变详情数字 |
| 疾行突击 | 在支持的阵形/兵种条件下 | 机动 +10% | 核对整合包追加计算、实际移速、路线和水陆分支 |

可以进一步增加地形、兵种、阵形、友军数量或战法来源条件；每个条件需要真实语义核对。周围友军条件先实现自身增幅，邻军增益光环之后再做，避免误把原生连携加成算成插件加成。

## 需要新增专项验证的机制

光环、直接减伤、异常免疫、伤兵恢复和士气保护的详细规则见 [进阶效果设计](SPECIAL_EFFECTS_ADVANCED.md)，包括叠加、期限、来源和原生结算边界。

| 机制 | 例子 | 需要验证 |
| --- | --- | --- |
| 固定/比例减伤 | 每次减少 100 点伤害；火伤减少 30% | 最终伤害来源、普攻/战法/持续伤害分类及伤兵结算顺序；防御倍率不是直接减伤 |
| 异常抵抗/免疫 | 混乱持续减半、免疫止步 | 状态类别、施放者、实际目标、失败和已有状态，以及原生资格与计时 |
| 触发效果 | 击溃后获得短时攻军增幅、受击后获得护盾 | 只按已确认事件触发，去重；同一战法的多条效果不能算多次触发 |
| 友军增益光环 | 邻近两格友军防御 +5% | 六边形距离、军团到势力映射、来源记录、多人光环叠加及失效清理 |
| 士气与恢复 | 每旬恢复士气、伤兵转为可战士兵 | 原生 setter、上限、补兵/治疗、两阶段伤兵结算与可战士兵转换；不能只改显示或中间字段 |
| 战法强化 | 火矢伤害增加、战法持续延长 | 实际施放到实际目标链、参数语义及概率；持续火伤的来源不能用全局管理者代替 |
| 单挑/抓捕强化 | 提高触发或成功概率 | 判定前的概率/资格入口；现有结算观察器不能当作概率修改接口 |
| 新战法/模型特效 | 新技能动画、士兵模型发光 | 原生命令、资源及三维绘制生命周期，属于另一个扩展阶段 |

## 效果数据与生命周期

建议一条效果包含：效果 ID、名称、来源、目标资格、属性/数值、激活条件、层数上限、游戏日期或旬数期限、叠加分组、显示颜色/图标、状态版本。计算、地图标记、悬浮说明和详情解析读取同一个生效状态，不能分别判断。

区分武将生涯效果、当前出征效果、一次战斗临时效果：

- 生涯效果按已记录战绩派生，加载检查点后重新计算；需要人为选择/解锁的永久数据另存插件检查点。
- 出征效果需要部署身份及基准兵力，部队覆灭、合并/入城、重新出征和载入旧档时正确结束或恢复。
- 临时战斗效果需要触发事件去重和原生游戏日期/旬数期限；不使用现实时间五秒等 UI 动画计时作为游戏持续时间。
- 队伍指针、运行地址及屏幕坐标不持久化。多部队目标绑定和每帧绘制需要有界批处理，避免把全武将扫描放进原生计算或渲染回调。

仅对攻军、防御这类属性倍率，建议原生计算先结束，插件把同类百分比相加后只乘一次，并设独立上限；这要求现有曹仁 +10% 也作为同一效果项纳入，而不是保留原钩子再重复追加第二层。不同来源和最终实际增幅应列明。固定减伤、治疗、概率、时长分别定义规则，不能套属性乘法公式。

## 建议顺序

1. 将曹仁样本改为通用效果配置，统一实际生效状态、独立开关与显示接口。
2. 完成战绩成长、所属领地、士气和兵力比例四类条件下的攻防变化，先保持简单叠加和上限。
3. 验证攻城/破城/机动及邻军光环。
4. 再做直接减伤、异常抵抗、触发效果和恢复；最后处理概率改动及新增战法。

实施和验收需核对：自身/敌方及多个军团、父子开关、不累乘、多个效果叠加、条件进入和退出、水陆/阵形分支、部队覆灭与再出征、读取旧档恢复及真实计算/界面一致。此次不开始实施。
